Customer Shopping Behavior Analysis

📌 Project Overview

This repository contains my first data analytics project, focused on analyzing customer shopping behavior to extract meaningful business insights. The project demonstrates an end-to-end workflow using Python for data cleaning & feature engineering and SQL (MySQL) for analysis.


---

📂 Dataset

Rows: 3,900

Columns: 18

Data includes customer demographics, purchase details, reviews, discounts, subscriptions, and buying frequency.



---

🛠️ Tools & Technologies

Python: Pandas, NumPy, Matplotlib, Seaborn

Database: MySQL

Environment: Jupyter Notebook / VS Code



---

🔄 Data Cleaning & Preparation

Checked and handled missing values

Filled missing review ratings using category-wise median

Standardized column names (lowercase, underscores)

Verified data types and consistency



---

🧠 Feature Engineering

Created age groups using quartiles

Converted purchase frequency into number of days

Prepared cleaned data for SQL-based analysis



---

📊 SQL Analysis (Business Questions)

Revenue comparison by gender

Spending behavior of discounted vs non-discounted customers

Top products by average review rating

Shipping type vs average purchase amount

Subscriber vs non-subscriber spending analysis

Discount usage percentage by product

Customer segmentation (New, Returning, Loyal)

Repeat buyers and subscription relationship

Revenue contribution by age group



---

📈 Key Learnings

Importance of data cleaning before analysis

How feature engineering improves insight quality

Writing SQL queries to answer real business questions

Connecting Python analysis with relational databases

🚀 Conclusion

This project helped me build strong fundamentals in data analytics, which is essential for my journey toward AI/ML engineering. It reflects a real-world analytical approach rather than just coding.
